# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Report it privately through GitHub instead: on the repository page, go to **Security → Report a vulnerability**. You should get a reply within a week.

Please include:

- what is affected;
- how to reproduce it;
- the impact you expect.

## Supported versions

Only the latest commit on `main` is supported. Fixes are not backported.

## Scope

The app is designed for a home network. The threat model, what the code does about each threat, and the risks accepted on purpose are described in [docs/SECURITY.md](docs/SECURITY.md).
